## 🎯 What is CryptoNest?

**CryptoNest** is a professional cryptocurrency trading and NFT marketplace platform built with React. It features:

- 🔐 **Secure authentication** (JWT tokens)
- 💳 **Real crypto payments** (BNB & USDT on BSC)
- 🪙 **NFT trading** (Buy/Sell/Stake)
- 👥 **MLM referral system** (Multiple income levels)
- 📱 **Mobile-first design** (React + Tailwind)
- 🔗 **Blockchain integration** (Wagmi + Web3)
- 🔔 **Push notifications** (Firebase FCM)
- 📊 **Real-time data sync** (React Query)

## ⚙️ How It All Works (100-word summary)

```
User logs in with email/password.
JWT token saved in localStorage.
User connects crypto wallet (MetaMask).
Wallet address verified on BSC network.
User deposits money via BNB or USDT.
Payment sent to company wallet on blockchain.
Backend verifies transaction hash.
User balance updated in database.
All pages notified via custom events.
Dashboard refreshes showing new balance.
User can now buy NFTs or trade.
Profits tracked and displayed in real-time.
Referral earnings calculated automatically.
Push notifications sent via Firebase.
User can withdraw funds anytime.
Process is secure, fast, and transparent.
```
